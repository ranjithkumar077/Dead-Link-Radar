# Dead-Link-Radar

Dead Link Radar is a high-performance web crawler and broken link detector built with Java. It discovers, analyzes, and reports working and broken HTTP/HTTPS links across web pages.

## Key Features (Roadmap)
- Phase 1: Core URL Status Checker
- Phase 2: HTML Link Extraction using Jsoup
- Phase 3: Recursive Web Crawler Scanner
- Phase 4 & 5: Concurrency & Thread Pooling with Java `ExecutorService`
- Phase 6: Duplicate URL prevention with `HashSet` & Domain Filtering
- Phase 7+: Spring Boot REST API & Modern Interactive UI
